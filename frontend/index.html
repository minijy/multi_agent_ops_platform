领星开放平台凭证

完成下列步骤后再保存凭证，否则接口会返回鉴权或白名单错误。

  1. 在领星 ERP 设置 → 业务配置 → 开放接口 获取 App ID 与 App Secret
  2. 将本服务器出口 IP 加入领星开放接口白名单
  3. 在下方填写凭证，勾选启用此 Agent，并点击保存配置
金蝶云星空 WebAPI 凭证

私有云 DynamicFormService 对接。请先在金蝶后台完成第三方系统登录授权。

  1. 在金蝶云星空 基础管理 → 公共设置 → Web API 配置第三方系统登录授权
  2. 获取 账套 ID、应用 ID、应用密钥、集成用户名
  3. 填写服务地址（以 /K3Cloud 结尾），勾选启用此 Agent 并保存
